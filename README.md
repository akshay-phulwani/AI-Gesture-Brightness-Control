# AI Gesture Controlled Brightness Controller

A computer vision project that controls screen brightness using hand gestures.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Screen Brightness Control

## Features
- Real-time hand tracking
- Thumb and index finger distance detection
- Dynamic brightness control
- Live visual feedback
